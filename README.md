# KONFIGURA
## Эмулятор работы в командной строке UNIX-подобной ОС
## Этап 1: REPL
Цель: создать минимальный прототип. Большинство функций в нем пока 
представляют собой заглушки, но диалог с пользователем уже поддерживается. 
## Возможности
- Графический интерфейс, заголовок содержит имя VFS
- Парсер команд с корректной обработкой по пробелам через shlex
- Команды-заглушки: ls, cd - печатают имя и аргументы
- Команда exit - закрывает окно
- Обработка ошибок: неизвестная команда, незакрытые кавычки, пустой ввод
